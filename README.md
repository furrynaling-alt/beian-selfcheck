# 网站备案自检 · beian-selfcheck

一条命令，把一台 Linux 服务器按**中国网络法规**过一遍：翻墙/代理、赌黄诈站点、境内未备案对外开站、成批个人信息、明文凭据、发信合规、盗版镜像……**只读**，不装东西、不改配置、不自动处置。

> 给自己服务器做体检用的。查出来该停的停、该删的删 —— **由人决定**，工具只负责"发现"。

---

## 30 秒用法

```bash
bash scripts/beian_selfcheck.sh            # 人看的报告（终端）
bash scripts/beian_selfcheck.sh --md       # 直接出 Markdown 表格
bash scripts/beian_selfcheck.sh --html     # 出网页版，【检出项标红】
```

零依赖：只要 `bash` + 系统自带的 `ss / pgrep / find / grep / dig / curl`。没装 `dig`、`curl` 的项会自动跳过，不影响其它项。

## 级别怎么划

| 档位 | 级别 | 典型情形 |
|---|---|---|
| **涉刑 / 违法 / 不可逆** | **S+** | 成批个人信息泄露、明文密钥导致重大事故、赌博/色情/诈骗站点运营 |
| **立即处理 · 高危** | **S / A** | 翻墙代理对外服务、未备案域名对外 web、PCDN、无牌支付/发卡 |
| **限期整改** | **B / C** | 日志留存不足 6 个月、邮件无退订、发件人伪造、未授权商用模板 |
| **例行优化** | **D / E / F** | 开源版权声明缺失、旧日志无归档、授权凭证未归档 |
| **无** | `--` | 未检出（**什么都没有**） |

## 逐项对照（19 项）

| # | 名称 | 依据（简） | 怎么查 | 判定：算命中 | 命中后 |
|---|---|---|---|---|---|
| 1 | 代理 / 翻墙类进程 | 《计算机信息网络国际联网管理暂行规定》6、14 条；公安部 33 号令 4、5 条 | `pgrep -af 'ss-server\|v2ray\|xray\|trojan\|tor\|wireguard\|openvpn\|hysteria\|sing-box\|clash\|gost\|frp\|nps'` | 有进程且不在登记业务里 | 停 + 禁用自启 + 清配置（S） |
| 2 | 特征端口监听 | 《互联网信息服务管理办法》4 条 | `ss -tlnp`，看公网地址上有无 1080/8388/8443/2053/2083/2087/2096/9115/10086 | 端口无法对应登记业务 | 核业务；无主端口必追（S） |
| 3 | 代理类配置目录 | 同 1 | `ls -d /etc/{shadowsocks*,v2ray,xray,trojan*,wireguard,sing-box,clash,openvpn}` | 目录里有可用配置（服务器地址/端口/密码） | 删（S） |
| 4 | 开机自启 / 定时拉起 | 同 1 | `systemctl list-unit-files --state=enabled` + `crontab -l` + `/etc/rc.local` | 有代理类单元被 enabled，或 crontab 里有拉起脚本 | 说明有长期运营意图 → 清（S） |
| 5 | PCDN / 流量转卖 | 《电信条例》7 条 | `pgrep -af 'pcdn\|网心云\|玩客云\|赚钱宝\|onething\|xycdn'` | 有客户端 / 流量与业务规模明显不匹配 | 停（S） |
| 6 | 发卡 / 支付类可疑服务 | 《非银行支付机构监督管理条例》 | 找 `*faka* *epay* *pay*` 站点与"码支付/四方支付"字样 | 未持牌却自建收款/发卡 | 停（S+） |
| 7 | 赌黄诈 / 私服外挂站点 | 《刑法》303、363、364、217 条；《网络安全法》47 条 | 站点目录搜关键词 | ⚠️ **必须人工看上下文** | 涉运营 → S+ |
| 8 | 盗版 / 侵权分发 | 《著作权法》；《刑法》217 条 | 找影视/软件/文档分发目录、torrent | 对公网分发 | 清（A） |
| 9 | 站点内容关键词 | 《互联网信息服务管理办法》15 条（九不准） | 同上 | ⚠️ **误报率最高**，审核词表/隐私页/申诉页天生含词 | 人工复核后销项（C） |
| 10 | 未备案对外提供 web | 《互联网信息服务管理办法》4、19 条；《非经营性互联网信息服务备案管理办法》 | `grep server_name /etc/nginx/...` + 查本机公网 IP 归属国 | **境内**机器 + 对外站点；走 CF/隧道**也算**对外提供服务 | 备案或挪境外（S） |
| 11 | 上传 / 评论接口被滥用 | 《网络安全法》21 条；公安部 33 号令 5 条 | 上传目录里找 `.php/.jsp/.sh` | 上传目录出现可执行文件 = webshell 风险 | 清 + 收紧（A） |
| 12 | 成批他人个人信息文件 | 《个人信息保护法》13 条；《刑法》253 条之一 | 全盘搜身份证号正则（csv/txt/xlsx） | 同一文件成批出现且来源不明 | 删 + 查来源（**S+**） |
| 13 | 日志留存 ≥ 6 个月 | 《网络安全法》21 条第 3 项 | 看 logrotate / journal 配置与最老日志 | 留存窗口不足 6 个月 | 调轮转（B） |
| 14 | 密钥 / 口令明文 | 《数据安全法》27 条；《个人信息保护法》51 条 | 搜 `AKIA...`、`-----BEGIN PRIVATE KEY-----`、`password=` | 真实可用且未吊销 | 入库 + 删文件（**S**） |
| 15 | 破解软件 / 非官方镜像 | 《著作权法》；《计算机软件保护条例》24 条 | 找 kms/activator/keygen/crack/破解、`*.esd`、GHO | 破解工具、改版系统镜像 | 清（D；出货/分发则 S） |
| 16 | 模板 / 源码授权 | 《著作权法》；各开源许可证 | 工具判不了 | 需人工核采购凭证 / 开源许可 | 补授权或换（B） |
| 17 | 群发特征与退订入口 | 《互联网电子邮件服务管理办法》13、14 条 | 找群发脚本 + 是否带退订 | 批量相似邮件且无退订 | 加退订/降频（B） |
| 18 | 发件人伪造 / SPF·DKIM·DMARC | 同上 12 条；RFC 7208/6376/7489 | `dig TXT <域名>` | 对外发信域名缺 SPF/DKIM/DMARC | 配齐（B） |
| 19 | 退信率 / 黑名单 | 同上 13 条 | 人工查 Spamhaus DBL | 退信率持续 >5% | 清洗名单（B） |

## 单机查不出来、要单独看的 5 类

| 项 | 依据 | 为什么单机查不到 |
|---|---|---|
| 境内服务器未备案对外提供 web | 《互联网信息服务管理办法》4、19 条 | 境外机器查出来是"未检出"，但你**境内那台**可能正踩着 |
| 生成式 AI 服务 | 《生成式人工智能服务管理暂行办法》(2023) 4、17 条 | 跑对外 AI 机器人要核备案与内容标识 |
| 数据出境 | 《个人信息保护法》38 条；《数据出境安全评估办法》 | 境内用户数据放境外机器 = 可能构成出境 |
| 等保定级备案 | 《网络安全法》21 条；等保 2.0 基本要求 | 系统要定级并备案 |
| 区块链信息服务 | 《区块链信息服务管理规定》(2019) | 做链上存证/节点服务要备案 |

## 四个容易踩的坑

1. **子串误报**：`apport-autoreport` 里含 `tor`、`libkms_message` 里含 `kms` —— 按名字抓代理/激活工具时会自己咬自己。命中先确认是不是子串匹配。
2. **关键词自带命中**：内容审核词表、申诉页、隐私政策页、404 页本来就写着"色情/赌博/诈骗"。这类标 `C`，人工看上下文后再定。
3. **ICP 备案只管境内机器**：脚本会查本机公网 IP 归属国；境外机器报"未备案对外开站"是假命中。反过来，境内机器哪怕走 CF 隧道也算对外提供服务。
4. **工具只做"发现"**：不自动停服务、不删文件。
