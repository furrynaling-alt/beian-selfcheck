# 网络条例大全（自查用对照）

> 自查时真正用得上的条文都在这儿了；**要正式引用请查现行有效版本**。

## 一、网络与信息服务基础

| 法规 | 管什么 |
|---|---|
| 《中华人民共和国网络安全法》 | 网络安全义务总纲；**第 21 条**（等级保护、日志留存不少于 6 个月）、第 24 条（实名）、第 46/47 条（不得传播违法信息）、第 59 条（罚则） |
| 《互联网信息服务管理办法》（国务院令 292 号） | ICP 备案与许可；**第 4 条**（未取得许可/未备案不得提供服务）、**第 15 条**（九不准）、第 19 条（罚则） |
| 《非经营性互联网信息服务备案管理办法》（信部令 33 号） | 备案怎么办、变更与注销 |
| 《互联网域名管理办法》 | 域名注册实名、不得为违法网站提供服务 |
| 《电信条例》 | 第 7 条 经营电信业务须取得许可（PCDN、流量转卖、私搭线路都踩这条） |
| 《计算机信息网络国际联网管理暂行规定》+ 实施办法 | **第 6、14 条**：国际联网必须用国家批准的信道（翻墙的直接依据） |
| 《计算机信息网络国际联网安全保护管理办法》（公安部 33 号令） | 第 4、5 条：不得擅自建立/使用非法信道，联网单位备案与安全管理义务 |
| 《关键信息基础设施安全保护条例》 | 被认定为关基后的额外义务 |
| 《网络安全等级保护条例》/ 等保 2.0 系列标准 | 系统定级、备案、测评 |
| 《网络安全审查办法》 | 关键信息基础设施运营者采购网络产品服务 |
| 《云计算服务安全评估办法》 | 为党政机关/关基提供云服务要过评估 |
| 《密码法》《商用密码管理条例》 | 商用密码使用、检测认证 |

## 二、内容与账号

| 法规 | 管什么 |
|---|---|
| 《网络信息内容生态治理规定》 | 平台内容治理义务、不得传播违法信息 |
| 《互联网用户账号信息管理规定》 | 账号实名、名称头像不得违法 |
| 《互联网跟帖评论服务管理规定》 | 评论服务提供者的审核与实名义务 |
| 《互联网论坛社区服务管理规定》 | 论坛备案与主体责任 |
| 《互联网直播服务管理规定》 | 直播资质与内容 |
| 《互联网群组信息服务管理规定》 | 群组建立者/管理者的管理责任 |
| 《互联网新闻信息服务管理规定》 | 采编发布新闻要许可 |
| 《未成年人网络保护条例》 | 涉未成年人内容与保护 |
| 《生成式人工智能服务管理暂行办法》(2023) | **第 4 条**（内容红线）、**第 17 条**（提供具有舆论属性或社会动员能力的生成式 AI 服务，应按《互联网信息服务算法推荐管理规定》履行备案与安全评估） |
| 《互联网信息服务深度合成管理规定》 | 深度合成内容标识义务 |
| 《互联网信息服务算法推荐管理规定》 | 算法备案与公示 |
| 《区块链信息服务管理规定》(2019) | 链上信息服务要备案、实名、不得用于违法 |

## 三、数据与个人信息

| 法规 | 管什么 |
|---|---|
| 《数据安全法》 | 数据分类分级、**第 27 条**（安全保护义务）、第 32 条（合法采集） |
| 《个人信息保护法》 | **第 6 条**（最小必要）、**第 13 条**（合法性基础）、**第 38 条**（出境条件）、**第 51 条**（加密/去标识/权限） |
| 《数据出境安全评估办法》 | 达到阈值的数据出境要先评估 |
| 《个人信息出境标准合同办法》 | 未达评估阈值的出境路径 |
| 《个人信息安全规范》(GB/T 35273) | 落地操作标准 |
| 《刑法》第 253 条之一 | 侵犯公民个人信息罪（**成批名单 = 刑事**） |

## 四、违法内容（刑事）

| 法规 | 管什么 |
|---|---|
| 《刑法》第 285、286 条 | 非法侵入/破坏计算机信息系统（外挂、改机、非法信道常涉） |
| 《刑法》第 287 条之二 | 帮助信息网络犯罪活动罪（给诈骗/赌博引流、收款、发卡都踩） |
| 《刑法》第 303 条 | 赌博罪、开设赌场罪 |
| 《刑法》第 363、364 条 | 传播淫秽物品 |
| 《刑法》第 217 条 | 侵犯著作权罪（盗版站点） |
| 《刑法》第 225 条 | 非法经营罪（无牌支付、非法电信业务） |
| 《反电信网络诈骗法》 | 第 21、25 条：不得为诈骗提供技术支持/支付帮助/引流；《反洗钱法》配套 |

## 五、知识产权与授权

| 法规 | 管什么 |
|---|---|
| 《著作权法》《著作权法实施条例》 | 作品使用授权 |
| 《计算机软件保护条例》第 24 条 | 未经许可复制/发行软件（破解、KMS 激活） |
| 《信息网络传播权保护条例》 | 网络传播授权与通知删除 |
| 各开源许可证（MIT/Apache/GPL/AGPL） | 保留版权声明与许可条款；AGPL 还要求提供源码 |

## 六、发信 / 邮件

| 法规 | 管什么 |
|---|---|
| 《互联网电子邮件服务管理办法》（信部令 38 号） | **第 12 条**（不得伪造发件人身份、发件头须真实）、**第 13 条**（须为接收者提供退订）、**第 14 条**（未经同意不得发送商业性邮件） |
| RFC 7208 / 6376 / 7489 | SPF / DKIM / DMARC 技术标准 |
| Spamhaus / 反垃圾邮件组织名单 | 被列入名单会导致大批收件方拒收 |

## 七、金融 / 交易类（跑量化、做金融内容会用到）

| 法规 | 管什么 |
|---|---|
| 《证券法》 | 证券投资咨询业务须持牌；不得承诺收益 |
| 《证券市场程序化交易管理规定（试行）》(2024) | **程序化交易要报告**（账户、策略类型、最高申报速率等），高频另有要求 |
| 《期货和衍生品法》+ 期货交易所程序化交易报告要求 | 期货程序化交易报告 |
| 《刑法》第 176、192 条 | 非法吸收公众存款、集资诈骗（承诺保本收益的"理财"踩这条） |
| 《防范和处置非法集资条例》 | 不得公开宣传、承诺回报 |

## 自查时的引用建议

报告「依据」列**一条主条 + 一条兜底**就够，例如：

```
1  代理/翻墙类进程   《计算机信息网络国际联网管理暂行规定》第 6、14 条；公安部 33 号令第 4、5 条
10 未备案对外提供 web 《互联网信息服务管理办法》第 4、19 条；《非经营性互联网信息服务备案管理办法》
14 密钥/口令明文     《数据安全法》第 27 条；《个人信息保护法》第 51 条
```

不要只写"违反网络安全法"——太糊，出事时说不清。
